# Livre blanc ICES v4.0

- `IC_ICES_WHITEPAPER_sceau-ingenierie-publique_v4.0_2026-10-25.tex` et `.pdf` : le livre blanc, conforme au guide de rédaction d'IntrepidCore v7.0 (couverture double marque IntrepidCore et IntrepidLab, style éditorial ambiance Marque, citations IEEE).
- `ices-livre-blanc-bibliographie.bib` : bibliographie.
- `figures/` : figures vectorielles et `make_figures.py` qui les produit.
- `ic-editorial.tex`, `ic-motifs.tex` : bibliothèque graphique du style éditorial (ouvertures de partie). Éléments de marque, non couverts par la licence.
- `../assets/` : logos IntrepidCore et IntrepidLab, nécessaires à la compilation.

Compilation : `xelatex`, `biber`, `xelatex`, `xelatex`, depuis ce dossier.

Statut : `in_review`, classification `public`, publication prévue le 2 novembre 2026. La version 3.0 de juillet 2026 est remplacée (SUPERSEDED) ; elle reste dans l'historique du dépôt documentaire d'IntrepidCore.
